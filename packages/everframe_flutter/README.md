# Everframe Flutter capture core (dry run)

This unreleased package shares masked Flutter render-boundary capture and a bounded, in-memory safe-frame replay buffer between the web and desktop probes. It has no reporter, native bridge, outbox, or production support claim. The magenta scan is a test sentinel; a complete sensitive-widget registry remains required before reporting real customer content.
