# Frozen Android-diagnostic-era Payload callers

Compile these callers against the protocol immediately before optional Apple evidence was added, save the object/class bytes, then run those unchanged callers against the candidate protocol. Supply a Payload containing Apple evidence and assert that the copied output retains it while updating `extra`. Repeat with the older eleven-field callers in `../diagnostic`; both generations remain supported. Do not recompile the saved callers against the candidate.

Kotlin `check-crash-model-compat.mjs --model Payload` checks the older public descriptors as well. Android diagnostic supporting type names remain stable when quicktype introduces the Apple sibling schema.
