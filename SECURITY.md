# Security policy

Please do not disclose a suspected vulnerability in a public issue.

Report it through the repository's private
[security advisory form](https://github.com/scriptx-com/traceitx-releases/security/advisories/new).
Include the affected SDK and version, reproduction steps, and the potential
impact. We will acknowledge the report and coordinate remediation and disclosure
through the private advisory.

Only the latest released SDK versions receive security fixes.
