New package (preview): JavaScript crash and error reporting for Amazon Vega OS apps (React Native for Vega 0.72, Hermes 0.12) with no native module. Reports uncaught errors, unhandled promise rejections and `captureException`, stores each report in AsyncStorage before sending it as JSON, and names the bundle so uploaded source maps symbolicate the frames.
